## 本轮边界

静态交互原型先确定产品行为；最终确认 A+B 合并方案，并已同步落地到生产 Web、移动 PWA 与桌面 Electron 壳。

术语固定如下：

- **桌面应用**：Electron 透明悬浮窗，可上下翻转。
- **桌面 Web**：浏览器页面，控制区固定顶部，不翻转。
- **手机 Web**：PWA / 浏览器页面，控制区固定顶部。

## 会话生命周期

| 动作 | 行为 | 上下文 |
|------|------|--------|
| 开始 | 创建新的 `sessionId`，冻结语言、水平、界面 / 释义语言、音频来源和设备等设置 | 新对话场景 |
| 暂停 | 立即停止新音频；封存有效 partial；允许已在途 STT / LLM 完成；释放麦克风 / 系统采集 | 保留同一 session、模型、上下文和 UI |
| 停止 | 封存、定稿并持久化；总结与短标题在后台生成 | 下次开始一定是新场景 |

- 删除「转写开关」：运行即转写。
- 保留会话内 AI 建议开关：关闭时转写继续、旧卡保留、不发新 LLM；暂停 / 继续保持状态，新会话默认开启。
- 活跃会话包括 running 与 paused；会话定义类设置在两种状态都锁定。
- 会话时长不计暂停时间。
- 主动退出先封存保存；崩溃、刷新或系统中断恢复为「意外暂停」，供用户继续或停止并保存。
- 每轮文字和状态都即时持久化；原始音频不落盘。历史本地长期保留，直到用户清除。
- 停止后立即可开启新会话，不等待总结。总结失败可从历史重试；进程退出后下次启动继续后台任务。

## 桌面悬浮窗

- 默认 `420 × 640`，最小约 `360 × 420`，最大宽约 `680`，最大高不超过当前屏幕工作区。
- 按显示器分别记住位置与尺寸。首次启动放在鼠标所在显示器右下角，距工作区边缘约 24px。
- 使用与 AIRI 一致的八向边缘 / 四角命中区缩放；命中区本身不可见，不显示四角圆点。连续细边框只在指针位于悬浮窗内容或缩放命中区时显示，移开后完全隐藏。窗口是响应式容器，不做整体 UI 缩放。
- Island 使用内容固有宽度并水平居中；转写和便利贴宽度跟随悬浮窗。
- 通过 Island 的四向箭头把手拖动；拖动中不翻转，松手后按 Island 中心所在半屏决定方向，并在中线附近保留滞回区。
- Island 位于下半屏时内容在上，上半屏时内容在下；翻转时尽量保持 Island 的屏幕坐标。
- 内部语义顺序永不倒置：`转写 → 当前便利贴 → 旧一轮 → 旧二轮`，因此转写永远比便利贴更靠近屏幕上方的一侧。
- 透明空白区域点击穿透；只有可见内容、Island 与细微 resize hit area 接收指针。

便利贴按容器高度显示且不重叠，最多三轮。所有端、所有轮次都保持正直，不再旋转或横向错位；旧轮逐轮降低不透明度，最旧轮底部渐隐。

转写带只显示当前 lane：realtime partial；定稿后保留最新 turn，直到下一轮开始。用低强调的「我 / 对方」区分 speaker，不额外显示「草稿中」字样；暂停保留，停止后只读。

尚未得到候选时不放空白黄色占位卡；只显示 Island 与已有转写。首次生成候选时可显示 skeleton；骨架严格复用最终卡的三候选结构、内边距和分隔线，避免完成时跳动。后续 `[]`、失败或请求中继续保留上一轮已提交卡片。

## 桌面高频控制与退出

Island 直接放：状态、相邻的暂停 / 继续与停止、AI 建议开关、拖动把手。`···` 菜单放：历史、设置、隐藏、退出。

- 暂停无确认。
- 停止需确认「停止并保存」，并说明下次开始会创建新对话。
- 退出需确认；活跃时文案为「结束会话并退出」，已停止时为普通退出。
- macOS 状态栏菜单纳入 MVP，详见桌面 Island 文档。图标 MVP 使用静态品牌图标；动态图标状态明确延期。
- 完成首次引导后，桌面应用以状态栏工具为主，默认不占 Dock；悬浮窗隐藏后始终可从状态栏菜单找回。

## i18n 与设置

新增 `uiLang: zh | ja | en`：

- 首次按操作系统语言初始化一次：`zh* → zh`、`ja* → ja`、其它 → `en`，之后持久化。
- 只能在已停止 / 无活跃会话时切换。
- 切换后界面立即生效；下一次会话的候选 `meaning` 跟随该语言。
- 用户界面删除独立「翻译语言」设置。内部 `meaningLang` 作为会话快照由 `uiLang` 派生，允许与 `conversationLang` 相同。
- 产品界面做中 / 日 / 英三语；Playground 仍保持中文实验室标签，但使用同一派生语义并可测试 `uiLang`。

设置不再复用 Onboarding 卡。宽屏使用左侧分类导航 + 右侧内容，移动端使用纵向分组；普通设置立即保存，无「保存」按钮。分类如下：

1. 通用：界面语言、主题（跟随系统 / 浅色 / 深色）、登录时启动（桌面，默认关）。
2. 对话：对话语言 + 对应水平；桌面音频来源；桌面真实麦克风设备。
3. 声纹：状态、重新录制、删除。
4. 权限：麦克风；桌面系统音频 / 屏幕录制。
5. 数据与隐私：清除历史；清除个人数据并重置。
6. 关于：版本、退出。

running / paused 时锁定：界面语言、对话语言、水平、音频来源、麦克风设备、声纹重录 / 删除、清除历史和重置。仍可修改主题、登录时启动、会话内 AI 开关，并可查看权限状态。

模型配置和名称完全不向用户展示，也不能选择或删除。只显示通用准备状态，例如「正在准备语音能力 68%」；个人重置不删除模型文件。深色模式下便利贴仍保持明亮黄色。

## 首次引导

- 界面语言不是独立步骤：右上角放普通下拉框，默认使用首次读取的系统语言，切换后整页立即生效。
- 主体先确认对话语言与该语言水平，再完成声纹录入；Onboarding 的「确认并继续」保留明确提交语义。
- 首次进入时后台准备语音能力，只显示通用进度，不显示模型名、提供方或缓存管理。
- 首次引导同时请求麦克风与系统音频 / 屏幕录制两个权限；不延迟到用户第一次选择系统音频时才请求。

## 权限、声纹与音频

- 首次引导一次请求麦克风和系统音频 / 屏幕录制两个权限；设置始终列出相关权限和状态 / 操作。
- 声纹是所有音频模式的硬门槛。重录采用原子替换；删除需确认并阻止开始，直到重新录入。
- 桌面音频来源：麦克风、系统音频、麦克风 + 系统音频。
- 同时采集时保持两路：mic = user，system = other，不混音。提示佩戴耳机并保留 echo cancellation；MVP 不做 STT 文本跨源去重。
- 桌面提供真实麦克风设备选择（系统默认 / 内置 / AirPods / USB 等），仅停止时可改并持久化。设备在活跃会话中断开时进入意外暂停并要求重选。
- Web / PWA 只用麦克风与浏览器 / 系统默认设备，不展示音源和设备选择。

## 本地历史与标题

- 历史在本地无限期保留，直到用户主动清除；保存文字、候选、总结与会话元数据，不保存原始音频。
- 会话停止时先用「本地化日期时间 + 对话语言」作为可用标题；后台总结任务再生成一个使用冻结 `uiLang` 的短场景标题。
- MVP 不提供会话重命名。

## 错误与恢复

- 短暂错误自动重试并用 toast 提示；持续错误固定显示在状态区 / Island，直到恢复。
- STT 失败时，当前转写带标明该段失败，正式 turn 仍留在历史。
- LLM 失败保留旧便利贴，并只提供对本次失败请求的「重试」；这不是「换一批」。
- 权限或音源错误阻止开始，并引导用户打开对应系统设置；不显示 provider / model 等技术名称。

## Web 主布局（A+B 已确认）

共同约束：建议优先、最新转写次之；控制区始终固定在顶部；便利贴不旋转。日语候选必须显示汉字假名标注，并高亮助词。

| 方案 | 宽屏 | 窄屏原型表达 |
|------|------|--------------|
| A 专注舞台 | 建议居中；完整对话从侧边 Sheet 展开 | 同一舞台，浮动入口打开对话 |
| B 双栏工作台 | 左侧完整对话，右侧建议舞台 | 「建议 / 对话」切换 |
| C 舞台 + 窄轨 | 建议舞台 + 右侧紧凑对话轨，可展开 | 建议舞台，按需展开对话层 |
| A+B 可折叠工作台 | 双栏等高且分别内部滚动；左栏收起后完全回到单栏舞台。标题旁横向「对话记录」按钮始终可见，展开时显示激活态，点击同一按钮收起 | 单栏建议舞台；同一按钮打开 / 收起占满内容区的对话层 |

生产 Web 已采用 A+B：宽屏为等高、分别内部滚动的可折叠双栏；窄屏为单栏建议舞台，并用同一常驻按钮打开或收起内容区内的对话层。

## 明确不做 / 延期

- 不做「换一批」。
- 不做点选 / 高亮候选，也不把候选选择写入 LLM 上下文。
- 不点击旧轮便利贴。
- MVP 不发系统通知。
- MVP 状态栏图标不做运行 / 暂停 / 错误动态图标变体。
- MVP 桌面只支持 macOS；保留跨平台 tray 的实现扩展性，但不在本轮实现。
